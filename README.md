# 封筒印刷ツール (iyakusai-envelope)

富山大学 医学薬学祭(医薬祭)実行委員会の**封筒に宛名を直接印刷する**ためのツールです。
封筒の絵を見ながらGUIで位置を合わせ、**封筒の実寸PDF**を作って印刷します。

**インストールは要りません。ブラウザで開くだけです。**

👉 **使う: https://mastermk2.github.io/iyakusai-envelope/**

## 使い方

1. 上のURLを開く
2. **封筒を選ぶ**(長3窓付 / 角2)
3. 右のパネルで**宛名を打つ**。位置は封筒の上でドラッグするか、mmの数値を直接入れる
   - **何通もまとめて刷るとき**は「CSV / Excel を読む」で一覧を読み、
     宛名の文字の中に列名のボタンで `{{会社名}}` のような**差し込み欄**を入れる。
     1件ずつプレビューでき、チェックを外した件は刷られません
4. **「点検」欄を見る**。窓からのはみ出し、差出人との重なり、フォントに無い文字、
   **データが空の列**を教えてくれる(警告があると上のバーに⚠が出ます)
5. **「PDFを作る」**でPDFを保存する(日本語フォントを丸ごと埋め込むので1〜3MBになります。何通ぶん作っても大きさはほぼ変わりません)
6. **まず「校正ページ」を封筒に1枚だけ刷る**（初めての封筒・初めてのプリンタのときは必ず）
   - 印刷設定は **「実際のサイズ」/「カスタム倍率 100%」・「用紙に合わせる」はOFF**。ここを間違えると全部ズレます
   - 封筒は手差しトレイに1枚ずつ
   - 刷った紙には**目盛り・十字マーク・100mmのスケールバー・使い方**が入っています
7. 校正ページを見て直す
   - **100mmのバーが定規で100mmでない** → 印刷設定が縮小しています。設定を直してもう一度
   - **十字マークが書かれた座標にない** → ズレた量を右下の**「ズレの補正」に mm で入れる**(マイナスも可)
   - **カギ形マークと実物の窓がずれている** → 封筒の窓の値がロット違いです。[docs/封筒の実測方法.md](docs/封筒の実測方法.md) を見て直してください
8. 合ったら本番を印刷する(「PDFを作る」で保存、または「印刷用に開く」でそのまま印刷画面へ)

配置は**ブラウザに自動保存**されます。委員の間で受け渡すときは「配置を保存」でJSONを書き出し、相手が「配置を読込」で開きます。

## 対応封筒

| 封筒 | サイズ | 窓 | 用途 |
|---|---|---|---|
| 長3窓付 | 235 × 120 mm | あり(90.3 × 45.3 mm) | 請求書・添え状の郵送 |
| 角2 | 240 × 332 mm | なし | A4を折らずに送る・手渡し |

**新しい封筒を足す方法** → [docs/封筒の実測方法.md](docs/封筒の実測方法.md)

> ⚠ 長3は、手元の実物が旧ロット(〒930-0152)で、入稿データ(〒930-0194)と差出人の刷り位置が違う可能性があります。**印刷前に必ず実物で試し刷りしてください。**

## 後輩のみなさんへ(メンテナンスの手引き)

### 中身

```
index.html            画面。封筒やテンプレートを足すときはここに script を1行足す
css/app.css           見た目。色は先頭の :root にまとまっている
js/registry.js        封筒定義・テンプレートの登録口
js/units.js           mm と pt の換算、フォントに無い文字の置き換え表
js/fonts.js           フォント読み込みと文字幅の計測(画面とPDFで同じ値を使う)
js/data.js            差し込みデータの読み込み(CSV/Excel)と {{列名}} の置き換え
js/layout.js          文字を行に組む。自動縮小もここ
js/state.js           状態と保存(localStorage)
js/render.js          封筒と要素をSVGで描く
js/ui.js              右パネル・ドラッグ・点検
js/pdfout.js          PDFを作る
js/calib.js           校正ページ(位置合わせ用の試し刷り)を作る
js/app.js             起動とボタンの配線
data/envelopes/*.js   封筒の実測値
data/templates/*.js   最初に開いたときの配置
data/sample/          動作確認用の架空の宛名データ(実データではない)
fonts/                Zen Kaku Gothic New (SIL OFL)。*.b64.js は file:// 用
vendor/               pdf-lib・fontkit・SheetJS(ネットには取りに行かない)
tools/                フォントを差し替えたときに使うスクリプト
```

### 直すとき

- **ビルドもインストールも要りません。**ファイルを直して保存し、ブラウザを再読み込みするだけ
- ローカルで動かすなら、このフォルダで `py -m http.server 8765` を実行して `http://localhost:8765` を開く
  (`index.html` をダブルクリックしても動きますが、サーバ経由の方が読み込みが速い)
- 分からないところは、**リポジトリごとAIに渡して「〜を直して」と頼む**のがいちばん早いです
- **ES Modules(`import`)は使わないでください。**`index.html` をダブルクリックで開いたときに動かなくなります

### 絶対に守ること

- **宛名データ・企業名・住所・金額を、このリポジトリに入れないこと。**Publicリポジトリです
  (`.gitignore` で `*.csv` `*.xlsx` `*.pdf` は除外してありますが、最後は目視で確認してください。
   `data/sample/` だけは例外で、中身は**架空のデータ**です)
- 読み込んだ宛名データは**ブラウザの中だけ**で処理され、どこにも送信されません。
  ブラウザにも保存しない作りなので、開き直したら読み込み直してください(個人情報を残さないため)
- 封筒の入稿データやスキャンもコミットしません。**そこから測った数値だけ**を `data/envelopes/` に書きます
