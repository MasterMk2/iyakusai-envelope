# 封筒印刷ツール (iyakusai-envelope)

富山大学 医学薬学祭(医薬祭)実行委員会の**封筒に宛名を直接印刷する**ためのツールです。
封筒の絵を見ながらGUIで位置を合わせ、封筒の実寸PDFを作って印刷します。

**インストールは要りません。ブラウザで開くだけです。**

## これは何のために作ったか

2026年8月の請求書25通の発送で、封筒への直接印刷をPythonスクリプトで作った。
発送はできたが、**座標を直すたびにスクリプトを書き換える**必要があり、
窓付き封筒で宛名が窓の下端ギリギリになる事故も起きた(実物に入れた写真で初めて発覚)。

封筒作業は領収書・契約書郵送・協賛依頼と毎年繰り返し発生する。
**委員が自分で位置を合わせて刷れる**ようにするのがこのツールの目的。

詳しい背景は [docs/要件定義書.md](docs/要件定義書.md) の §1 にある。

## 対応封筒

| 封筒 | サイズ | 窓 | 用途 |
|---|---|---|---|
| 長3窓付 | 235 × 120 mm | あり | 請求書・添え状の郵送 |
| 角2 | 240 × 332 mm | なし | A4を折らずに送る・手渡し |

新しい封筒は `data/envelopes/` にJSONを1つ足せば増やせる(実装後)。

## 使い方

実装後にここへ書く。手順の骨子は次のとおり。

1. URLを開く
2. 封筒を選ぶ
3. 宛名データ(CSV/Excel)を読む、または直接打つ
4. 位置を合わせる
5. **校正ページを1枚試し刷り**してズレを測る → ズレをmmで入れる
6. 本番を印刷する(**印刷設定は「実際のサイズ」「用紙に合わせるOFF」が必須**)

## 後輩のみなさんへ(メンテナンスの手引き)

- このツールは **HTML + JavaScript だけ**でできている。ビルドもインストールも不要
- 直したいときは、リポジトリごとAIに渡して「〜を直して」と頼めばよい
- **宛名データ・企業名・住所を、このリポジトリに絶対に入れないこと**(Publicリポジトリのため)
- 封筒の実測値や運用の経緯は [docs/要件定義書.md](docs/要件定義書.md) にまとまっている
